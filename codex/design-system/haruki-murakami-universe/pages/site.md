# 网站页设计系统覆盖

本页覆盖自动生成的 Master 配色与字体建议，并作为六个页面和一个作品详情页的实际实现依据。自动结果中的粉色强调、圆角组件与联网字体不适合本项目的文学杂志方向，因此不采用。

## 视觉方向

- 定位：独立文学杂志的作家档案页。
- 记忆点：首页的唱片式同心圆，以及角色页的深墨绿双向关系板。
- 原则：纸面、留白、细线、克制；卡片不做统一大圆角，不用渐变光效。

## 色彩

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 纸面 | `#f1efe7` | 页面底色 |
| 纸面浅层 | `#fbfaf5` | 卡片与阅读面板 |
| 墨色 | `#1b2420` | 主文字、重点边框 |
| 次级文字 | `#4e5a53` | 正文说明 |
| 辅助文字 | `#5c665f` | 年份、标签与说明，保持至少 4.5:1 对比度 |
| 墨绿 | `#315a4b` | 强调、选中状态 |
| 深墨绿 | `#203f35` | 关系板、深色阅读步骤 |
| 分隔线 | `#c7cbc1` | 纸刊网格与边界 |
| 焦点色 | `#1d6282` | 键盘焦点环 |

## 字体

- 标题：`Songti SC`、`STSong`、`Noto Serif CJK SC`、`Source Han Serif SC`、`SimSun`。
- 正文：`PingFang SC`、`Hiragino Sans GB`、`Microsoft YaHei`、`Noto Sans CJK SC`、`Source Han Sans SC`。
- 不加载在线字体，所有字体回退到本机系统。

## 间距与结构

- 采用 `0.25rem / 0.5rem / 0.75rem / 1.25rem / 2rem / 3rem / 4.5rem / 7rem` 的八级间距。
- 页面最大宽度 `74rem`，两侧使用 `clamp(1.1rem, 4vw, 3rem)` 随屏变化。
- 桌面端以十二列网格组织首页入口；内容页采用七比五或八比四的信息与侧栏比例。
- 手机端在 `52rem` 以下收起主导航，在 `38rem` 以下将主要卡片改为单列。

## 组件与状态

- 卡片：以细线和纸面色块建立边界，圆角不超过 `2px`；悬停只上浮 `3px` 并增加纸面阴影。
- 按钮：最小触控高度 `2.75rem`；主按钮使用墨绿底，次按钮使用墨色描边。
- 角色卡：选中时使用双层墨绿边框；共享作品的角色使用深蓝描边。
- 阅读步骤：当前步骤切换为深墨绿底；标签使用原生按钮与 `aria-selected`。
- 焦点：所有可操作控件保留 `3px` 外露焦点环；动效在减少动态偏好下关闭。
